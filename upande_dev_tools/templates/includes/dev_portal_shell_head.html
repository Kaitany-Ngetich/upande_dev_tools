{# Every dev portal page should include this from inside a `head_include` block override, not from the page body: `templates/base.html` (which `templates/web.html` extends) defines a real `head_include` block, so a page can do: {% block head_include %} {{ super() }} {% include "templates/includes/dev_portal_shell_head.html" %} {% endblock %} That puts the stylesheet and font tags in the actual document (so preconnect hints do what they're for, and the stylesheet is requested as early as possible) instead of mid-, where they still work but not as intended. #}
